SuperBrain

SuperBrain is a self-hosted AI second-brain app for saving and organizing digital content, including YouTube videos you choose to analyze. This page describes the djbclark/superbrain fork’s YouTube API client for compliance and quota reviews.

YouTube Used via official YouTube Data API Services with user-granted OAuth access.

Legal: Privacy Policy · Terms of Service · Google Privacy Policy · YouTube Terms of Service

What the YouTube integration does

  • OAuth sign-in so you can authorize SuperBrain on your Google account
  • Read subscriptions for channel update / WebSub workflows
  • Create and update your private category playlists (playlist create/update/item insert)
  • Does not use youtube.search.list
  • Videos are opened on YouTube (or shown via official thumbnails); SuperBrain is not a substitute YouTube client UI for playback embedding in this fork

Revoke access anytime: Google Account → Third-party access
